# 项目功能概览

本项目是药房自动化现场的查询、下单和设备运维工具，主要有以下功能：

| 功能 | 可以做什么 |
| --- | --- |
| 登录与权限 | 账号登录、退出，区分管理员和普通用户 |
| 仪表板 | 查看最新订单、机器人处理进度、任务状态和异常提示 |
| 数据加载 | 从本机路径、设备配置、云端库位接口或上传文件加载数据 |
| 药品查询 | 查询药品信息、库位、抓取工具及知识属性，支持扫码、筛选和排序 |
| 库位编辑 | 修改库位、货架属性和挡板高度 |
| 数据导出 | 下载数据包、Knowledge 文件、库位配置和缺失清单 |
| 药品下单 | 选择药品和库位、扫码下单，查看提交结果 |
| 测试下单 | 生成或导入测试清单、组合选品、批量提交、再次下单和导出记录 |
| 订单管理 | 查询订单详情、更新零售单信息、取消订单、转人工和人工完成 |
| 人工确认 | 处理机器人待确认提示，支持手动确认和自动确认 |
| 地图导航 | 查看地图、雷达和机器人位置，设置停留点、导航、巡逻、回桩和重定位 |
| 建图与地图编辑 | 采集地图、导入导出、备份恢复，编辑虚拟墙、轨道和区域 |
| 底盘遥控与健康 | 手动控制底盘移动，查看电量、定位和故障信息 |
| 机械臂 | 在工具内访问机械臂示教器 |
| 日志与服务控制 | 查看实时日志，启动、停止和重启业务服务 |
| 文件管理 | 浏览宿主机文件，预览、上传、下载和重命名 |
| 终端与远程桌面 | 在浏览器执行命令、访问宿主机图形桌面 |
| 现场设置 | 配置工作模式、下单接口、门店、虚拟键盘和飞书 |
| 飞书上报 | 预览或提交订单结果、上传异常截图，可选 AI 辅助分析异常 |
| 部署维护 | 启动服务、构建应用包、更新、回滚、查看版本和运行日志 |

说明：具体操作受账号权限、工作模式及设备连接状态限制；创建订单仅在测试模式开放，但仍会提交到配置的 Broker。
